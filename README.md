# Agentic Design Systems

A course workspace for designing with AI agents, Python and Grasshopper. You won't just *use* an AI here. You'll build the system it works inside: the briefs it reads, the skills that shape its judgement, the tools it calls and the measures that say what "good" means.

## Getting started

1. Open this folder in **VS Code** (File › Open Folder…). Keep it in a normal local folder, not Downloads, and preferably not a synced OneDrive or iCloud folder.
2. Open the **Claude Code** panel and sign in.
3. Type **`/setup`**. The agent installs what's needed, checks your computer, and makes your first tower.

## What's in here

| Folder | What it is |
|---|---|
| [sessions/](sessions/) | Each session's plan, concepts, exercises and materials. Start with [Session 1](sessions/01-think-in-systems/README.md) |
| [studio/](studio/) | **Your workspace**: your briefs now, your own design system later |
| [.claude/skills/](.claude/skills/) | Skills the agent can use, including the ones you write |
| [examples/tower/](examples/tower/) | The Tower Toy: a complete small design system to study and copy |
| [kit/](kit/) | Course plumbing (the Grasshopper bridge, run folders, the gallery). Read it, don't change it |
| `runs/` | Created as you work: one folder per design, and `runs/gallery.html` to compare them |
| [CLAUDE.md](CLAUDE.md) | What the agent is told about this project at the start of every session |

## Skills you can call

- `/setup`: get this computer ready, or check it when something breaks
- `/tower-designer`: design towers for a client card (the worked example)
- `/course-tutor`: explain a concept, explain some code, or quiz you
