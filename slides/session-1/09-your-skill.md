# Write your own skill

Write a skill, in **your folder**, that uses the dice. For example:

- *Crit order*: who presents first?
- *Random client*: roll to build a client from lists of who, what and where
- *Board game referee*: for a game you've just invented

1. Decide what the skill should do, and what it must **never** do.
2. Ask Claude to create a new skill in `.claude/skills/`, starting from `tie-breaker`. Then edit the text until it says what *you* mean. The writing is the part you do yourselves.
3. Start a **new session**, so that Claude sees the new skill.
4. Run it, and adjust the text if it doesn't behave.

> **You're done when** your skill works, and you can answer: **what can your skill not make the tool do?** Try asking it for a 7 on a six-sided die.
