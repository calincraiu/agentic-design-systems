# AI is a family. An LLM is the one that writes.

<div data-widget="figure" data-name="ai-family"></div>

> Which of these have you already used? Where does your favourite render tool sit?

<!-- notes -->
**The idea.** "AI" is a wide word, like "building". It helps to know which kind you're talking about.

- **Artificial intelligence** is any program that does something we'd call clever. A chess engine counts, and so does a route planner.
- **Machine learning** is the part of AI that *learns from examples* instead of following rules someone wrote. A spam filter learns from millions of emails marked as spam.
- **Generative AI** learns from a huge collection, then *makes new things* that fit it.
- An **LLM** (large language model) is generative AI for text: text in, text out. Claude, GPT and Gemini are LLMs. Many can also *read* images, but what they write is text.
- An **image model** is generative AI for pictures. Midjourney, Stable Diffusion and most AI render plugins are image models.

The line is blurring: some newer models both read and make pictures. The split on the diagram is about what each kind is mainly for.

What learning produces is called a **model**: a very large file of numbers, tuned until it's good at one kind of making.

**Why it matters.** Claims about "AI" mean little until you know which kind. A render tool and Claude are different models that work in a similar way: both make what is *likely* to fit. This course is about the LLM, and about the system you build around it.
