# Groundwork

<p class="lead">Where you'll work, what you'll write, and a folder of your own.</p>

<!-- notes -->
Six short, practical slides: the two tabs of the desktop app, file extensions, plain text files, and the two folders the course uses. Then you make your own folder and copy the first two kits into it, so you can try each part of the system as it is introduced.

If you get stuck later in the session, the cause is often something from this section: the wrong folder open in the Code tab, a hidden `.claude` folder that didn't get copied, or a note saved as `CLAUDE.md.txt`.
