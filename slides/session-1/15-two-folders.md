# Two folders: the tutorial, and your project

<div data-widget="figure" data-name="folders" data-start="1"></div>

> Claude works inside a folder. So we keep the lesson and your work in separate ones.

<!-- notes -->
Claude Code works inside one folder at a time. It reads, creates and changes files there, so the course keeps two folders apart.

- The **course folder** is the one you unzipped. It holds this app, the slides and the kits. You read it and run it, but you don't build anything in it, and your copy is set up so that Claude won't edit it.
- **Your own folder** starts empty today. Your `CLAUDE.md`, your skills and your tools go there, and it's the folder you open in the Code tab when you want Claude to work on your project.

A **kit** is a small set of files, for example a tool and a skill, that you copy from the course folder into yours. Copying only goes in that direction.

Keeping the two apart means you can always tell your own work from the course material, and so can Claude. It also means a skill you've broken can be fixed by copying the kit again. If something you wrote seems to have disappeared, the usual cause is having the wrong folder open in the Code tab.
