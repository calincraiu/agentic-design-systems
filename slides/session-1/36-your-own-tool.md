# Your own tool

<p class="lead">Design a tool by writing down what it promises.</p>

<div data-widget="figure" data-name="contract" class="map"></div>

<!-- notes -->
**In this section.** So far you've used other people's tools. Now you design one, without writing code. You write its **contract**: what goes in, what rule it applies, what comes out, and a few test cases worked out by hand. Claude writes the code to match, and your test cases decide whether it's right. The map shows the loop: the two dark boxes are yours, the code is Claude's. When a test fails, the dashed arrows are the question you'll keep asking: is the code wrong, or did the contract say the wrong thing?
