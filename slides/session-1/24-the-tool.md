# The tool

<p class="lead">Something that really does the thing.</p>

<div data-widget="figure" data-name="parts" data-ghost data-start="0" data-focus="2" class="map"></div>

<!-- notes -->
The LLM can't be relied on to calculate exactly or to choose fairly. A **tool** can, because it is a small program that does one exact thing. This section shows two complete tools, one that adds and one that rolls dice, and the one-line command that runs them.

A **program** is a list of exact instructions that a computer follows the same way every time. The course's tools are written in **Python**, a programming language that reads close to English and is common in design software (Rhino and Grasshopper both run it). Python files end in `.py`. You won't need to write Python in this course, but you will be able to read a short program.

In the diagram, the tool sits outside the LLM. The model can't turn into a calculator. It can only be given one to use.
