# A file's name ends with what kind it is

<div data-widget="figure" data-name="file-kinds"></div>

> Can't see `.pdf` or `.dwg` after your file names? Your computer is hiding them. You'll switch them on in a few minutes.

<!-- notes -->
A file name has two parts: the name, and the **extension** after the last dot. You already know plenty of extensions, such as `.dwg`, `.3dm`, `.pdf`, `.docx` and `.jpg`. The extension tells the computer which program should open the file.

Most of those formats are stored in a way only their own program can read. Open a `.3dm` in Notepad and you get a screen of meaningless characters. A **text file** contains only characters, so any editor can open it, and so can Claude. This course uses two kinds: `.md` files for notes and instructions, and `.py` files for small programs.

Windows and macOS hide extensions by default. Then `add.py` shows up as just `add`, and a note saved from Notepad can quietly become `CLAUDE.md.txt`, which Claude won't pick up. You switch extensions on when you set up your folder; the steps are in the notes for that slide.

To see the difference, open a PDF in Notepad (Windows) or TextEdit (Mac), then open any `.md` file from the course folder.
