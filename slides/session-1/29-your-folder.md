# Start your own folder

1. **Make** an empty folder called `ads-yourname`.
2. **Open** it in the **Code tab**.
3. **Write** a short `CLAUDE.md` with Claude: who you are, one rule.

<!-- notes -->
**The idea.** This folder is yours for the whole module, and the `CLAUDE.md` is your first piece of authorship. It is a plain text file that Claude reads at the start of every session in this folder.

**Where to put it.** In your Documents folder (Windows) or your home folder (Mac). Avoid Downloads, and avoid OneDrive or iCloud folders if you can: they're slower, and they sometimes lock files.

**What to write.** Five lines is plenty, but make the words your own:

- **Who you are**: your course, your experience with code (probably none).
- **How you like things explained**: plain language, an architectural example, no jargon without a definition.
- **One rule it must keep.** A good one: *never make up a number or a roll: use the tools.* You'll add the tools on the next slide.

**Safety net.** The Code tab keeps **checkpoints**: you can rewind a conversation and most of the file changes it made. And the course folder is never touched, so you can always copy a kit again.
