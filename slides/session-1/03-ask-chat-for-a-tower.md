# Ask Chat for a tower

> In the Chat tab, start a new conversation and paste:
>
> **"Design a tower on a 30 × 30 m plot next to a park: calm, but noticed from the river. Give me the number of floors, the floor height, the total height, the floor area and the shadow it casts on the park."**

> Everyone on the same model, please: the one the app picks by default.
>
> Read the answer. Then **keep that conversation open**: you'll come back to it at the end of the session.

<!-- notes -->
**The idea.** This is how most people use AI: you ask, it answers. You probably got a confident, well-written answer with numbers in it, and perhaps a name for the tower. That is the bottom step of what this course calls the *ladder of authorship*: **prompting**.

Look at the answer as a client would. Where did each number come from? Was the floor area worked out, or written because it sounded right? What did it assume about the park, the river and the sun? Did it say so? You can't tell yet, and that's the point. Keep the answer: at the end of the session, you give the same wish to a system you've built yourself, and compare.

**Why it matters.** Everyone in the room asked for the same tower, with the same words. That makes the comparison at the end fair: same wish, two ways of answering it.

**Why the same model.** Today the room's answers get pooled: this one, the long sum and the fairness poll. That only works if everyone is asking the same thing, so use the same model, and switch memory off if your account has it on.

**Try it yourself.** Ask the same thing in a second new conversation. Do the numbers match? If they don't, which one would you believe, and why?
