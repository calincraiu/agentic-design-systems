# Start your own folder

1. **Show** file extensions and hidden items in your file browser (see the notes).
2. **Make** an empty folder called `ads-tutorial`.
3. **Open** it in the **Code tab**.
4. **Write** a short `CLAUDE.md` with Claude: who you are, one rule.

<!-- notes -->
This folder holds all your work for the module, and its `CLAUDE.md` is the first thing you write. Claude reads `CLAUDE.md` at the start of every session in this folder. You set it up now, before the concepts, so you can try each part of the system in your own folder as it comes up.

First, make file extensions and hidden items visible. The next slide copies a `.claude` folder, and you need to see it to check that it arrived.

- **Windows 11**: in File Explorer, View › Show, and tick both **File name extensions** and **Hidden items**.
- **Windows 10**: in File Explorer, on the View tab, tick both **File name extensions** and **Hidden items**.
- **Mac**: in Finder, Finder › Settings › Advanced, tick **Show all filename extensions**. For hidden items, press **Cmd + Shift + .** (full stop) in any Finder window.

Put the folder in Documents (Windows) or your home folder (Mac). Avoid Downloads, and avoid OneDrive or iCloud folders if you can. Syncing slows them down and can lock a file while Claude is writing to it.

About five lines is enough for `CLAUDE.md`. Write it with Claude, but make sure the wording is yours:

- who you are: your course, and how much code you've written (none is fine)
- how you want things explained, for example in plain language, with an architectural example, and with terms defined the first time they come up
- one rule it must keep. A useful one for today is *never make up a number or a roll: use the tools*. The tools arrive on the next slide.

If something goes wrong, the Code tab keeps **checkpoints**, so you can rewind a conversation along with the edits Claude made to files directly. Changes made by commands it ran, such as a tool writing into `runs/`, aren't covered. The course folder never changes, so you can always copy a kit again.
