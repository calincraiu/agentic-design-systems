# Start your own folder

1. Make an **empty folder** somewhere normal, such as `Documents/ads-yourname`. Avoid Downloads, OneDrive and iCloud if you can.
2. In the Claude app, open the **Code** tab and choose that folder.
3. **Write your first context.** Ask Claude to create a `CLAUDE.md` with you: who you are, how you like things explained, and one rule it must always keep. Keep it to about five lines, and make the words yours.
4. **Take the dice kit.** Paste the prompt below into the Code tab. It copies the dice tool and the tie-breaker skill into your folder.
5. Start a **new session** and type `/tie-breaker`.
