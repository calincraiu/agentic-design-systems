# An LLM on its own

In the Claude app's **Chat** tab, type:

> Pick a random number from 1 to 20.

Call out your number. Is that what random looks like?

An **LLM** (large language model, the AI itself) writes text that *fits*. It wrote something that looks like a random number. Nothing was rolled.
