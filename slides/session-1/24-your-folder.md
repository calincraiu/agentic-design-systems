# Start your own folder

1. Make an **empty folder** called `ads-yourname`, in your Documents folder (Windows) or your home folder (Mac).
2. Open it in the **Code tab**.
3. With Claude, write a short **CLAUDE.md**: who you are, how you like things explained, one rule it must keep.
4. **Copy the prompt below** from the course app on *your* computer, and paste it. It copies the add and dice kits into your folder.
5. Start a **new session** and ask for the total of a few room areas, **without** naming a skill. Did Claude use `add-up` by itself?

<!-- notes -->
**The idea.** This folder is yours for the whole module, and the `CLAUDE.md` is your first piece of authorship. Five lines is plenty, but make the words your own. One rule worth keeping: *never make up a number or a roll: use the tools.*

The prompt asks Claude to copy the kits from the course folder into yours. The path in it is found by the course app on *your* computer, so copy it from there, not from the projector.

**Step 5 is the surprise.** You never typed `/add-up`, yet Claude used it. At the start of the session it read the skill's two-line *description* ("use when the student asks for a total…") and recognised your request. That description is how a skill gets picked, so it's worth writing carefully. If Claude didn't pick it, read the description: would *you* have known to use it?

**If something goes wrong:**

- **Avoid Downloads**, and avoid OneDrive or iCloud folders if you can. They're slower, and they sometimes lock files.
- If the hidden `.claude` folder didn't come across, ask Claude to list `.claude/skills/`. If it's still missing, use the zip link under the prompt.
- A new skill only shows up in a **new session**.

**Safety net.** The Code tab keeps **checkpoints**: you can rewind a conversation and most of the file changes it made. And the course folder is never touched, so you can always copy a kit again.
