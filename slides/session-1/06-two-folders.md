# Two folders

<div data-widget="figure" data-name="folders" data-start="1"></div>

> The course folder can be replaced at any time. Your folder can't.

<!-- notes -->
**The idea.** In this course you work with two folders, and keeping them apart saves a lot of trouble.

- The **course folder** is the one you unzipped. It holds this app, the kits and the examples. You run it and read it, but you don't work in it. A fresh copy replaces it each session.
- **Your own folder** starts empty today. Everything you author goes there: your `CLAUDE.md`, your skills, the tools you take away and the tools you design. Nobody replaces it.

A **kit** is a small set of files (a tool and a skill, for example) that you copy from the course folder into yours. Copying only ever goes in that direction.

**Why it matters.** Anything you change in the course folder disappears when it's replaced, and changing it can break the app. If something you wrote has gone missing, check which folder you were in.

**Try it yourself.** Look at the chip at the bottom right of every slide. It always says where you should be working: the Chat tab, the Code tab with your folder open, or this app.
