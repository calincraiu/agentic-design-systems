# The skill

<p class="lead">Know-how you write down once.</p>

<div data-widget="figure" data-name="parts" data-ghost data-start="0" data-focus="4" class="map"></div>

<!-- notes -->
Left to itself, an agent decides how to go about a task, and not necessarily the way you would. A **skill** is a short text file that tells it how to approach one kind of task: which tool to use when, in what order, and what it must never do.

You run two skills from your own folder: `add-up`, which never does arithmetic itself, and `tie-breaker`, which never makes the choice itself. Each one addresses a problem from the LLM section. Then you change a rule in one of them and see the behaviour change.
