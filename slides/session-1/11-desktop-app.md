# The Claude desktop app: one program, two tabs

<div data-widget="figure" data-name="desktop-app"></div>

> **Chat** talks. **Code** works in a folder. Behind both tabs: the same model.

<!-- notes -->
The Claude desktop app is a single program with tabs along the top of the window. Two of them matter in this course.

**Chat** is a conversation. You write, Claude replies.

**Code** works inside a folder you pick on your computer. Claude can read the files in it, create and change files, and run small programs. The name is misleading for this course: you won't be writing code. It means Claude can act on files rather than only talk about them.

Both tabs use the same model. What differs is what each tab gives that model to work with.

The chip at the bottom right of each slide says which tab to be in. Chat is used for questions and polls, Code for anything in your own folder.

Open the app and switch between the two tabs. Code asks you to pick a folder before you can start.
