# How would you know if any of this is good?

A tool made these towers from a few numbers each. An agent could make hundreds. Today you start building the system it works inside.

<!-- notes -->
This question runs through the whole module. An agent can produce dozens of design options in an afternoon, each with a fluent description. Neither the number of options nor the description tells you whether any of them is good. To judge that, you need a few things written down:

- a **brief** that says what you want
- **skills** that say how the work should be done
- **tools** that make and measure things exactly
- **measures** that turn "better" into something you can check and argue about

Over four sessions you write each of these yourself. Today starts with deliberately small examples, adding numbers and rolling a die, before moving on to a tower.

The towers in the image were all made by one tool, from a handful of numbers each. You use that tool in Part 2.
