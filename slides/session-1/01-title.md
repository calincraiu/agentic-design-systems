# How would you know if any of this is good?

A tool made these towers from a few numbers each. An agent could make hundreds. Today you start building the system it works inside.

<!-- notes -->
**The idea.** This module keeps coming back to one question: when an AI agent produces design options for you, how would you know whether any of them is good? A confident description is not an answer. Neither is a nice image.

Over four sessions you build the parts that *can* answer it:

- a **brief** that says what you want
- **skills** that say how the work should go
- **tools** that make and measure things exactly
- **measures** that turn "better" into something you can argue about

The agent works inside what you write. You decide.

**Today.** You start by asking Chat for a tower, the way most people use AI. Then a short look at what actually answered you, some groundwork, and you set up your own folder. Part 1 meets the parts of the system one at a time (the LLM, the tool, the agent, the skill and context), using the smallest examples we could find: adding up, and rolling a die. You try each part in your own folder as you meet it. Part 2 puts the parts to work on a tower, and at the end you compare what you got with what Chat gave you at the start.
