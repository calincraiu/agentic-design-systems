# Same contract, new engine

<p class="lead">A Grasshopper definition becomes a tool once it has named inputs, named outputs and a contract.</p>

<div data-widget="figure" data-name="gh-tool" data-start="4" class="map"></div>

<!-- notes -->
In Session 1 the tools were Python files. Here the engine is Grasshopper, but the idea of a tool hasn't changed: fixed inputs with allowed ranges, a rule applied the same way every time, outputs, and a contract that says all of this in plain words. Claude doesn't open the canvas or rewire anything. It sends values in and reads results out.
