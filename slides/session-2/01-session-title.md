# Tools you make

Grasshopper definitions as tools, and a skill that judges with them.

<!-- notes -->
In Session 1 Claude used Python tools that someone else wrote. In this session you make tools yourself, in Grasshopper, and Claude runs them the way it ran `add.py`. By the end your folder holds a chain: the tower on a real site, a measure you built, and a skill you wrote that judges towers with your own limits.

You need Rhino 8 or 9 with RhinoAI's MCP server and Ladybug Tools installed. The setup checklist went out before the session.
