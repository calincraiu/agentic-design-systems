# A chain of tools and skills

<div data-widget="figure" data-name="chain" data-start="7"></div>

> **Take-home:** a tool for your own studio project. Copy `tools/grasshopper/TEMPLATE.md` and write its **contract**: inputs, the rule in words, outputs, two test cases by hand, and what it can't tell you. Add one line: which skill would run it, and what its result would feed.

<!-- notes -->
Every link in the chain is a file in your folder: a site, a tower tool, measures, a skill that judges and a skill that designs. Two links are yours, `daylit` and `tower-check`, and you sit at the end, where the report arrives. Each tool takes inputs and returns outputs; each skill says, in words, which tools to run and what to do with the results. Swap a link and the rest still works, as long as the names and the contract stay the same.

The take-home starts the next tool. Pick something you check by hand in your studio project: a stair, a room schedule, a façade ratio, a distance to the nearest tree. Write the contract before any Grasshopper. Writing it forces the decisions that make a tool useful: what goes in (a layer, a number, a choice), in which unit, what exactly is counted, and what the number can't see. Work out the test cases on paper, on shapes simple enough to check by hand.

Keep your own folder as it is. The course folder is replaced with a fresh copy each session, but your folder isn't touched.
