<!-- notes -->
In Session 1 the tools were Python files. Here the engine is Grasshopper, but a tool is still the same thing: fixed inputs with allowed ranges, a rule applied the same way every time, outputs, and a contract that says all of this in plain words. You start with the smallest tool there is, adding two numbers, so that everything new is the Grasshopper side and not the arithmetic.
